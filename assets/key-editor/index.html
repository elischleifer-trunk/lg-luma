Streaming search keys

Search on your TV finds where shows stream with Movie of the Night, ranks them with TMDB and shows their Rotten Tomatoes and IMDb scores with MDBList. Keys are checked, then stored only on your TV.

From the Developers Platform, or a RapidAPI key for Streaming Availability.

The long token under TMDB → Settings → API, not the shorter API key.

For review scores on each poster. Under MDBList → Preferences, API access.

Keys never leave your network except to the service they belong to.
